ROAST MY RESUME

Paste resume text, get a playful roast, and see all useful grounded suggestions for making the resume clearer and stronger.

Proof-of-concept blueprint · Status: approved · Local website + small Node server + OpenRouter

HOW THIS WORKS

1 · Paste

Your resume stays in the page while you use the website.

2 · Send safely

A small server receives the text. It keeps the OpenRouter key out of browser code.

3 · Review

The server sends the resume through OpenRouter to the selected model and checks its reply.

4 · Show

The page shows the roast and suggestions; the app does not save them.

WHAT HAPPENS TO THE TEXT

The app does not save resumes or results in a database, browser storage, or app logs. To create a review, the website sends the text through OpenRouter to the selected model provider. Data handling depends on their applicable terms and settings. Do not enter sensitive information unless you have reviewed those terms.

FOLLOW THE USER JOURNEY

Paste the resume

Open the one-page website, paste text, and submit. Empty text is handled without sending an unnecessary model request.

Files: public/index.html · public/app.js

Ask the selected model for resume feedback

The server keeps the API key private, sends a focused resume-writing prompt, and checks that the reply is valid and grounded in the supplied text.

Files: server.js · server/openrouter.js

Read the results

A usable resume gets a short, non-cruel roast, all distinct prioritized quote-and-explanation suggestions, and matching rewrites in a separate section. Minimal input gets a roast only and no invented feedback.

STACK AND RUNNING IT

Plain HTML/CSS/JavaScript for the page; Node.js and Express for the small local server; OpenRouter and the selected model for the review. No database, login, upload, or separate deployment service.

Set OPENROUTER_API_KEY and OPENROUTER_MODEL=nvidia/nemotron-3.5-lightning:free in the local .env file, run npm install, then npm start and open http://localhost:5500.

Model availability, free-tier limits, and provider data terms can change; check them before submitting resume text.
