Roast My Resume: app map

Paste resume text and receive a playful Roast, grounded Real Talk suggestions, and matching rewrites on one vertically stacked page.

One review, end to end

The browser sends a review request to the local server. Reviewable text is checked and sent through OpenRouter; the result returns to the page.

Data handling: Resume text is sent to OpenRouter and the selected model provider. This app does not save resumes or results; provider handling depends on their applicable terms. Avoid pasting sensitive information.

A three-stop code route

  1. Find the page controls

    In public/index.html, look for #review-form and the result containers #roast-result, #feedback-list, and #rewrite-list.

  2. Follow submit and rendering

    In public/app.js, find form.addEventListener('submit', ...) and renderReview(). The handler sends resumeText; the renderer places quotes and explanations in Real Talk and rewrites in their separate list.

  3. Trace the API response

    In server.js, find POST /api/review. It applies input limits and calls createResumeReview() in server/openrouter.js, where validateReview() checks the response and quote grounding before the browser receives it.

To change this, start here

  • Page wording or card layout: public/index.html and public/styles.css.
  • Review tone, issue selection, or grounding rules: server/openrouter.js and server/reviewPromptExamples.js.
  • Minimum words, request limits, or local API behavior: server.js.
  • Provider credentials and model choice: the ignored local .env file; never put its values in this map or commit them.

A practice to reuse

The PRD requires each suggestion to quote actual resume text. validateReview() checks that every quote occurs in the submitted resume, and a live fictional resume check confirmed the returned quotes were grounded. On another project, turn a requirement into a visible test and check the actual output—not only the instructions that were meant to produce it.

Run it again

From the project folder, run npm.cmd start and open http://localhost:5500. The default port can be overridden with PORT; reviewable submissions need an OpenRouter key in the local ignored .env file.
